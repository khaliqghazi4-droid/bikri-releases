# Ghazify releases

Installer files for the Ghazify apps. Installed apps check this repo for updates.
No source code lives here.

## Download the latest version

- **Windows PC:** [Ghazify-Setup.exe](https://github.com/khaliqghazi4-droid/bikri-releases/releases/latest/download/Ghazify-Setup.exe)
- **Android phone:** [Ghazify-Phone.apk](https://github.com/khaliqghazi4-droid/bikri-releases/releases/latest/download/Ghazify-Phone.apk)

These links always give the newest version. Older versions are listed under
[Releases](https://github.com/khaliqghazi4-droid/bikri-releases/releases).

After installing, log in with your shop's email and password, or create a new shop.
